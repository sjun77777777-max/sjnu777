# 스쿨 럭키포인트 (학교 웹앱)

이 폴더는 브라우저에서 실행되는 학교 상점·보상 앱입니다.

## 학교에서 여는 방법

`index.html`을 더블클릭하면(`file://`) 학교망에서 서버 연결이 막히고, 학생마다 데이터가 따로 저장됩니다. **https 또는 http 주소**로 여세요.

1. **권장:** 폴더를 학교 홈페이지, GitHub Pages, Netlify 같은 **https** 주소에 올립니다.
2. **교실 PC 한 대:** `학교사이트열기.bat`을 실행한 뒤 브라우저에서 `http://localhost:4173` 으로 엽니다. 같은 Wi-Fi의 다른 기기는 `http://그PC아이피:4173` 으로 접속할 수 있습니다.
3. 온라인 명단·상점을 같이 쓰려면 Google Sheets + Apps Script를 쓰고, 이 폴더의 `server_apps_script.gs`로 **다시 배포**해야 합니다.

## 이 앱이 하는 일

- **통계**: 학생회가 엑셀(.xlsx) 또는 CSV를 올리면 홈·통계 탭에 그래프와 표로 보여 줍니다.
- **학생**: 학생회 명단에 있는 이름·반만 가입할 수 있습니다. 로그인하면 내 통계를 보고 보상을 구매할 수 있습니다.
- **학생회**: 홈페이지를 관리합니다. (명단 등록, 자료 업로드, 공지, 규칙). 이 사이트에서는 상점·벌점을 지급하지 않습니다.

## 온라인(공유) 모드로 여러 사람이 같이 쓰기

같은 통계와 명단을 같이 쓰려면 **공유 DB(서버)**가 필요합니다.

가장 쉬운 방법은 **Google Sheets + Apps Script**를 서버로 쓰는 것입니다.

- `server_apps_script.gs` 파일을 참고해서 Apps Script 웹앱으로 배포한 뒤,
- 배포 URL을 앱의 설정에서 “온라인 API URL”로 설정하면 됩니다.

엑셀 통계를 온라인으로도 같이 보려면, 배포한 Apps Script를 이 폴더의 `server_apps_script.gs` 내용으로 **다시 저장·배포**해야 합니다.

## 핵심 규칙(앱에 반영)

- **상점·벌점**: 이 홈페이지에서 지급하지 않습니다. 엑셀 통계로만 보여 줍니다.
- **보상 상점**
  - 상점 **2점** → 학습지 재발급권
  - 상점 **3점** → 책 재발급권
  - 상점 **6점** → 급식 우선권 (친구 1명당 **+3점**)
- **상쇄점**: 이 홈페이지에서 관리하지 않습니다.
- **통계**: 올린 엑셀의 숫자 열·반 열을 읽어 평균·상위 막대 그래프와 표를 만듭니다. 반 평균 상점이 기준 이상이면 특별활동 가능(아이디어 반영)

## 백업/복원

설정 탭에서 **내보내기/복원** 기능으로 데이터를 텍스트로 백업할 수 있습니다.

## 가입(학생)

- 학생회가 먼저 이름과 반을 명단에 올립니다.
- 학생은 홈에서 **학교 이름 + 이름/반 + PIN** 으로 가입합니다. 명단에 없는 이름은 가입되지 않습니다.
- 가입 후 자동 로그인되어 **내 상태 확인/보상 구매**가 가능합니다.
